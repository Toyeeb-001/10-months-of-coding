# 🚀 Terminal-Based Computer Science Quiz Game

A clean, interactive Python Command Line Interface (CLI) quiz application designed to test foundational computer literacy. This project features user input sanitization, dynamic string evaluations, an explicit mathematical grading matrix, and automated letter grading feedback loops.

---

## 💡 Project Purpose
I designed and engineered this system during my pre-university studies to master the core principles of Python programmatic logic, conditional execution tracks, data types, and defensive input validation frameworks.

---

## 🛠️ Key Technical Architecture Features
* **Defensive Input Validation:** Leverages string manipulation `.lower()` to process player answers equitably, neutralizing case-sensitivity conflicts.
* **Explicit Execution Matrix:** Manages game initialization prompts securely using strict logical check boundaries.
* **Isolated Score Arithmetic:** Decouples mathematical score percentages from display strings, optimizing performance and eliminating structural runtime errors.

## 🚀 How to Clone and Execute Locally

### Prerequisites
Ensure you have Python 3 installed on your local computer infrastructure. You can check your version by running:
\`\`\`bash
python3 --version
\`\`\`

### Installation Steps
1. **Clone the Repository:**
   \`\`\`bash
   git clone https://github.com
   \`\`\`
2. **Navigate to the Project Root Folder:**
   \`\`\`bash
   cd YOUR_REPOSITORY_NAME
   \`\`\`
3. **Execute the Application Engine:**
   \`\`\`bash
   python3 main.py
   \`\`\`
